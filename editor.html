Buka app + debug

Tambah hinaan.
Tanpa buka kode.

Pilih bagian, tulis kalimat, lalu export roast-library.js untuk menggantikan file di repo. Perubahan disimpan otomatis sebagai draft di browser ini.

Cara pakai (30 detik)
  1. Pilih Bagian dan sub-bagian di kiri. Keterangan di atas kolom tulis menjelaskan kapan kalimat itu dipakai.
  2. Tulis kalimat. Mau banyak sekaligus? Tempel satu kalimat per baris, semuanya ditambahkan dalam sekali simpan.
  3. Perhatikan pesan di bawah kolom tulis: duplikat, kepanjangan, atau lupa tanda baca.
  4. Klik Export roast-library.js, ganti file di repo, lalu naikkan angka ?v= di index.html dan editor.html.
Belum ada perubahan.

Belum tahu kalimat harus masuk mana? Taruh di INBOX. Engine tidak memakainya sampai kamu memindahkannya.
